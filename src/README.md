# Проект автотестов в школе iFellow

Проект API автотеста на Java с использованием Rest Assured, JUnit 5, Cucumber, Lombok и Allure Framework.

## Технологии
- Java 17
- Rest Assured
- JUnit 5
- Cucumber
- Allure Framework
- Lombok

## Запуск тестов

### Через Maven в командной строке:
```bash
# Очистка и запуск всех тестов
mvn clean test

# Просмотр отчета Allure
mvn allure:serve
```

### Через IntelliJ IDEA:
1. Открой Maven панель (справа)
2. Выполни `Lifecycle` → `clean` затем `test`
3. Для отчета: `Plugins` → `allure` → `allure:serve`

## Структура проекта
```
src/
├── main/java/ru/ifellow/alivenskiy/hw5/utils/     # Утилитный класс: TestConfig
└── test/java/ru/ifellow/alivenskiy/hw5/runners    # Запуск тестов через Cucumber: TestRunner
└── test/java/ru/ifellow/alivenskiy/hw5/steps      # Подробные шаги для воспроизведения тестов
└── test/java/ru/ifellow/alivenskiy/hw5/testUtils  # Утилитные тестовые классы
```

## Тест №1

## Allure отчет
После запуска `mvn allure:serve` откроется браузер. Во вкладке будет отчет, включающий в себя:
- Количество тест-кейсов;
- Описание каждого теста с понятными шагами;
- Наглядные графики;
- Время выполнения;
- Статусы тестов.
